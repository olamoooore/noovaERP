Engineer build rule

If a capability is used by two or more modules, or affects security, audit, workflow, documents, AI access, module activation, integration, or compliance evidence, review it as a Platform Core Service first.

Forbidden shortcut

  • No standalone onboarding engine per module.
  • No separate audit, attachment, numbering or template engine per domain.
  • No direct cross-module table access.
  • No AI bypass of user permissions.

Proof of completion

  • Module contract passed.
  • API contract and negative path tests passed.
  • Tenant isolation and permission tests passed.
  • Audit trail and idempotency evidence provided.
