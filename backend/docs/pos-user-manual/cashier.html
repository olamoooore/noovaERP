Getting Started

Before Your Shift

Make sure you have:

  • Your login credentials
  • Access to the POS terminal
  • Opening cash balance
  • Any special instructions from your supervisor

Opening Your Session

1Log In
Enter your username and password on the POS login screen
Click Sign In
2Select Terminal
System displays available terminals
Click on your assigned terminal (e.g., "Register 1", "Kiosk A")
System shows terminal details and warehouse
3Open Session
Click Open Session
Enter your opening cash balance (amount in drawer)
Optional: Add opening notes (e.g., "Starting with $500")
Click Confirm
✓ Session Opened
Your session is now active. You can see the session number and opening balance on screen. You're ready to process orders.
⚠️ Important: You cannot process any orders without an active session. If you see "No Active Session", go back and open a session first.

Offline Mode (Target State)

What Happens During Network Outage?

If the network connection is lost, the POS system can continue operating in offline mode:

1Network Lost
System detects network outage
Screen shows "Offline Mode" indicator
You can continue creating orders
2Create Orders Offline
Orders are created and stored locally
Payments are queued for processing
Continue normal order entry
3Network Restored
System detects network connection
Offline Mode indicator disappears
System automatically syncs queued orders
4Sync Complete
All offline orders are synced to server
Sync is idempotent (no duplicate orders)
All side effects applied (inventory, loyalty, GL)
You receive confirmation
ℹ️ Offline Sync: The sync process is idempotent. If the same order is sent twice, only one order is recorded. This prevents duplicate charges.

Troubleshooting

Common Issues

Issue Solution
Barcode won't scan Try manual product search. Check barcode for damage. Ask supervisor if issue persists.
Card payment declined Ask customer to try different card or payment method. Check card reader is working.
No active session Open a new session before processing orders. Click "Open Session" and enter opening balance.
Cannot void/refund order Void/refund requires supervisor approval. Call supervisor to approve the request.
Offline mode stuck Check network connection. Restart POS if needed. Contact IT support if issue persists.
Receipt won't print Check receipt printer is on and has paper. Restart printer if needed.

Key Reminders

⚠️ Session Required: Always open a session before processing orders. You cannot process orders without an active session.
⚠️ Approval Required: Void and refund operations require supervisor or manager approval. You cannot perform these alone.
ℹ️ Idempotency: All payments are idempotent. Duplicate payment requests produce no duplicate effect. This protects against duplicate charges.
ℹ️ Loyalty Points: Loyalty points are earned on payment and reversed on void/refund. Customer loyalty balance is always accurate.
ℹ️ Audit Trail: All transactions, voids, refunds, and approvals are logged for compliance and reconciliation.
