Manager Responsibilities

As a manager, you have the following responsibilities:

  • Configure POS terminals and payment methods
  • Manage user accounts and permissions
  • Monitor POS performance and compliance
  • Generate and review reports
  • Manage loyalty program settings
  • Handle escalations and exceptions
  • Ensure audit trail integrity
  • Manage system settings and configurations
ℹ️ Entitlement: All manager functions are validated through the entitlement system. You must have the "pos_manager" role to access manager features.

Troubleshooting

Common Issues

Terminal Not Responding

1Check Connection
Verify terminal is powered on
Check network connection (WiFi or Ethernet)
Restart terminal if needed
2Check System Status
Go to dashboard and check system health
If red, contact IT support

Offline Orders Not Syncing

1Check Network
Verify network connection is restored
Wait 5 minutes for automatic sync
2Manual Sync
Go to dashboard
Click Sync Offline Orders
System attempts to sync queued orders

Loyalty Points Not Reversing

1Check Configuration
Go to Loyalty Program settings
Verify loyalty reversal is enabled
2Check Audit Trail
Go to Audit Trail
Search for void/refund event
Verify loyalty reversal is logged
