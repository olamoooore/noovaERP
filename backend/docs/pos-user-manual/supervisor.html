Supervisor Responsibilities

As a supervisor, you have the following responsibilities:

  • Approve discounts exceeding cashier limits
  • Approve void operations
  • Approve refund operations
  • Monitor POS sessions and cashier activity
  • Handle escalations and exceptions
  • Ensure compliance with POS policies
  • Maintain audit trail integrity
ℹ️ Entitlement: All supervisor approvals are validated through the entitlement system. You must have the "pos_supervisor" role to approve operations.

Approving Discounts

When Discount Approval is Needed

Cashiers can approve discounts up to $50 or 10%. Larger discounts require supervisor approval.

1Receive Approval Request
Cashier requests discount approval at POS
You receive notification on your supervisor terminal
Notification shows order number, discount amount, and reason
2Review Request
Click View Request
Review order details:
• Customer name and ID
• Items in order
• Discount amount and percentage
• Reason provided by cashier
Verify discount is reasonable
3Approve or Deny
Click Approve or Deny
If denying, enter reason
Enter your supervisor credentials (username/password)
Click Confirm
4Approval Recorded
Approval is recorded in audit log
Cashier is notified of approval/denial
If approved, discount applied to order
If denied, cashier can request again or proceed without discount
⚠️ Approval Audit Trail: All approvals are logged with your name, timestamp, and reason. This creates an audit trail for compliance.

Handling Exceptions

Common Exceptions

Duplicate Payment Detection

If a payment is sent twice, the system detects it and prevents duplicate charge.

1Duplicate Detected
System shows "Duplicate Payment Detected" message
Shows original payment details
Shows duplicate attempt details
2Action
Click Use Original Payment
Duplicate is rejected
Original payment is used
No duplicate charge recorded

Offline Order Sync Issues

If offline orders fail to sync when connection is restored:

1Sync Failure Detected
System shows "Offline Sync Failed" message
Shows number of orders that failed to sync
Shows error details
2Action
Click Retry Sync
System attempts to sync again
If successful, orders are synced
If failed, contact IT support

Session Reconciliation Variance

If closing balance doesn't match expected balance:

1Variance Detected
System shows variance amount
Shows expected vs actual balance
Shows possible causes
2Investigation
Review session transactions
Check for missed cash movements
Verify all voids and refunds are recorded
Recount cash if needed
3Resolution
If variance is small (under $5), approve and record
If variance is large, investigate further
Document findings in session notes
Report to manager if needed

Compliance & Audit Trail

Audit Trail Requirements

All supervisor actions are logged for compliance:

  • Discount approvals logged with supervisor name, timestamp, and reason
  • Void approvals logged with supervisor name, timestamp, and reason
  • Refund approvals logged with supervisor name, timestamp, and reason
  • Session monitoring logged
  • Exception handling logged
ℹ️ Audit Trail Access: Audit logs are available in the manager dashboard for compliance review and reconciliation.

Key Reminders

⚠️ Entitlement Required: You must have the "pos_supervisor" role to approve operations. Your credentials are validated through the entitlement system.
⚠️ Audit Trail: All approvals are logged. Do not approve requests without proper review. Approvals are auditable and traceable.
ℹ️ Idempotency: All operations are idempotent. Duplicate requests produce no duplicate effect. This protects against duplicate charges and side effects.
ℹ️ Side Effects: When you approve void/refund, all side effects are reversed (inventory, loyalty, GL). This ensures data consistency across all systems.
